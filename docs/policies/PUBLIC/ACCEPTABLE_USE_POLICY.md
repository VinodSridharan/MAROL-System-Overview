# Acceptable Use Policy

**Effective Date:** January 28, 2026

## Permitted Uses

You may use MAROL for:
- Portfolio evaluation and technical interviews
- Proof-of-concept testing with documents you own or have permission to use
- Learning and experimentation
- Research and analysis (non-commercial)

## Prohibited Activities

You may NOT:
- Upload illegal, copyrighted (without permission), or confidential content
- Automate requests or circumvent rate limits (bots, scrapers, etc.)
- Share API keys or demo sessions with others
- Attempt security exploits, prompt injection, or data exfiltration
- Use MAROL for spam, phishing, or malicious purposes

## Enforcement (Automatic)

Abuse detection is **automated**:
- **Demo tier:** Session automatically terminated, IP temporarily blocked (no human review)
- **Evaluation tier:** Key automatically revoked for severe violations
- **Severe violations:** Logged for potential legal action

## Rate Limiting (Transparent)

- **Demo:** 3 sessions per IP per 24 hours (prevents abuse while allowing legitimate multi-device use)
- **Evaluation:** Fair use (no hard limits, but excessive automation triggers automated review)
